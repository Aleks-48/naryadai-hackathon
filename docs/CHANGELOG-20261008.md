# EnbekPlus: исправления 8 октября 2026

Этот архив заменяет серверный снимок с SHA-256 fef6930ab66e1e073f9cecece7015edcb73b0024faab0c42158563564e418964. Исходная аудиторская копия сохранена без изменений. Flutter поставляется отдельно.

## Исправлено

- Переназначение на бригаду выбирает только активного исполнителя с наименьшей текущей нагрузкой. Пустая бригада или бригада без активных работников возвращает 409. Отказ не меняет наряд, очередь/версию, аудит, уведомления или отложенную доставку. Уведомления новой бригаде адресуются только активным работникам.
- PWA передаёт rating_shift в фильтре рейтинга. Отчёт использует поддерживаемые API фильтры участка, оборудования и исполнителя; показывает отказы и текущую нагрузку раздельно. Простой можно связать с нарядом через order_id. Отчётные периоды/смены подписаны в UTC.
- Обычное нажатие обновления отчёта больше не воспринимается как запрос внешней AI-сводки. Сводка запрашивается только явным действием и разрешённой конфигурацией.
- Compose передаёт флаги LLM, сводки и Telegram с default 0, а токен и webhook secret Telegram с пустыми defaults. .env.example не содержит секретов. Инструкция ручного opt-in находится в README.
- PWA больше не ссылается на отсутствующий icon.svg: favicon, manifest и SW shell используют существующие PNG. Cache version обновлена до v14. Все перечисленные ресурсы проверены HTTP-запросами.

## Обновление локальной копии

1. Перед обновлением сохраните резервную копию текущих исходников и существующего data volume/SQLite и фото штатным способом. Не удаляйте работающие данные.
2. Перенесите исходники из EnbekPlus/ в тот же Compose-проект, сохранив свой локальный .env и настройки проекта/существующего тома. В архиве нет .env, базы или рабочих фото. Новый каталог с другим Compose project name может создать пустой том: проверьте имя проекта перед запуском.
3. Пересоберите и пересоздайте app штатной командой проекта, например docker compose up -d --build app. Не используйте down -v. Новая миграция БД этим патчем не добавлена.
4. Проверьте /api/health, вход мастера/исполнителя и требуемый сценарий. Перезагрузите страницу PWA онлайн, чтобы установить SW v14. Мобильное приложение использует прежний API; его обновление отдельно.
5. Если нужны внешняя LLM или Telegram, настройте их вручную локально по README. Не публикуйте .env, токены или раскрытый docker compose config. Этот архив ничего не активирует самостоятельно.

## Повторение тестов

После установки зависимостей requirements.txt в отдельное виртуальное окружение:

- python -m unittest discover -v
- node --check static/app.js
- node --check static/sw.js
- node --test tests/test_frontend_races.js
- python tests/run_streamlit_apptest.py
- python tests/run_flutter_v2_contract.py

Запускайте с NARYADAI_LLM_ENABLED=0 и NARYADAI_TELEGRAM_ENABLED=0, без рабочих секретов. Тесты используют временные синтетические базы. Contract script проверяет Python HTTP-запросы, совпадающие с Flutter v2, а не исполняет Dart.
