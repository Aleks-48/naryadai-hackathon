# EnbekPlus — пакет независимой проверки

## Назначение

Локальный MVP диспетчеризации ремонтных нарядов с ролями мастер, исполнитель и read-only руководитель. Все люди, оборудование, заявки, материалы и события в демонстрационной базе синтетические. Данные не относятся к реальному предприятию.

## Быстрый запуск

1. Установить Python 3.12.
2. Из корня проекта установить зависимости: `python -m pip install -r requirements.txt`.
3. Запустить `powershell -ExecutionPolicy Bypass -File .\start.ps1`.
4. Открыть `http://127.0.0.1:8765`.

Демо-пароль для всех seed-аккаунтов: `demo123`. Учётные записи перечислены в README. Не использовать эту конфигурацию для реальных пользователей.

## Проверки

Команды из корня проекта:

```powershell
python -m unittest discover -v
node --check .\static\app.js
python -m py_compile .\server.py .\tests\test_app.py
```

Набор из 11 тестов проверяет полный цикл наряда и роли, CSRF, закрытие мастером, причины отказа и паузы, отчёты, повторные и конкурентные запросы, истечение сессии, границы рейтинга и его корректировку, эскалацию таймеров, проверки MIME/размера/декодирования изображения, точные и близкие дубли, EXIF, пути файлов, разграничение доступа к фото, низкую уверенность модели и базовую PWA-поверхность.

## Границы доверия

- Авторизация и разграничение ролей выполняются сервером. Состояние UI не является защитой.
- Тексты для модели не разрешают опасные действия и не заменяют наряд-допуск, производственный контроль или решение уполномоченного сотрудника. Применимые внешние разрешения остаются самостоятельным условием работ; отсутствующий допуск может быть причиной отказа или паузы. Автоматическая оценка не должна штрафовать за это.
- Фото подтверждают только факт наличия файла и ограниченные технические признаки. Оценка 1–5 — проверяемость фотофайла, а не качество/безопасность ремонта. EXIF может отсутствовать или быть изменён; дата не доказывает свежесть. Фото не подтверждает исправность оборудования.
- Точная копия определяется SHA-256. Поиск похожих файлов использует perceptual dHash и цветовой признак, поэтому это эвристика: возможны пропуски и ложные совпадения. Подозрение требует подтверждения мастера.
- Когда нет настроенного совместимого LLM endpoint и внешнего ключа, приложение явно работает в `rules-only`. Секреты для внешнего вызова передаются только через отдельную конфигурацию процесса; ключ в пакет не включён.
- Telegram адаптер помещает уведомления только в локальную очередь. Бот, токены и внешняя отправка не настроены.
- Профиль PWA проверен как локальное веб-приложение. Реальное Android-устройство и Android-установка не проверялись. Кэшируется только оболочка; офлайн-очередь изменений не реализована.

## Ограничения MVP

Результаты тестов не являются независимым аудитом или гарантией производственной пригодности. Не проведены нагрузочное тестирование, аудит безопасности сторонней стороной, подключение к оборудованию/ERP, подтверждение норм конкретного предприятия, реальная проверка LLM/Telegram, проверка Android-устройства и production-развёртывание. Перед любым пилотом нужны проверка заказчиком правил допуска/эскалации и отдельная настройка инфраструктуры и доступа.
