# Mobile v3 относительно согласованной v2

## Изменённые файлы

- `lib/main.dart`: один import и read-only `AiReviewCard` в деталях наряда перед существующими действиями
- `lib/translations.dart`: добавлено 90 RU/KK/EN записей; все прежние 445 записей сохранены

## Новые файлы

- `lib/ai_review.dart`: ограниченный типизированный разбор JSON-строки анализа, обязательность решения мастера, проверки фото/материалов, независимая итоговая оценка мастера; обработка устаревшего анализа
- `lib/ai_review_card.dart`: адаптивная информационная карточка без сетевых запросов и действий
- `test/ai_review_test.dart`: правила/модель, null, malformed, unknown, границы и приватность, сохранение добавленных сервером замечаний, предыдущий анализ, итоговая оценка
- `test/ai_review_card_test.dart`: 3 языка × 2 темы × rules/model, узкий экран с 200% текстом; повреждённые/неизвестные данные; предыдущий результат; видимость финальной оценки всем ролям
- `test/ai_review_translations_test.dart`: динамические подписи и 4 точных server error mappings
- `test/ai_review_fixtures.dart`: исключительно синтетические результаты, без сети и секретов
- `tool/ai_review_regression.dart`: smoke-проверки чистого Dart без Flutter-зависимостей
- `tool/verify_review_source.py`: статическая проверка переводов, контракта и сохранения v2

## Сохранено без изменений

Остальные прежние production-файлы, tests/tools v2, `pubspec.yaml` и fragment зависимостей. Не изменялись API, права, принятие/закрытие/оценивание наряда, фото/Telegram и работа с секретами.

## Исправлено при независимом review

- Подавляется вложенный JSON в произвольном месте текстового поля; кавычки и многословные credential-shaped значения не обходят редактирование
- Старый анализ после доработки/новой сдачи явно отмечается как предыдущий
- Лимит замечаний учитывает детерминированные проверки, которые backend добавляет после максимум 20 замечаний модели

## Не входит в результат

Живой запрос к модели, настройка AI-ключей/провайдера, изменение backend, APK, Gradle wrapper JAR, Android/iOS scaffold. Нет подтверждённого прогона Dart/Flutter или проверки интерфейса на устройстве.
