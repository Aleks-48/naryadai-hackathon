# EnbekPlus Mobile v3: анализ и итоговая оценка

Полный пакет обновления исходников mobile v2: все прежние `lib`, `test`, `tool`, `pubspec.yaml` и новые изменения. Это не APK и не полный Android/iOS scaffold. Flutter/Dart SDK в проверочном облачном окружении отсутствует: компиляция, анализатор, Dart/Flutter-тесты и отображение на устройстве пока НЕ проверены.

## Что появилось

- В деталях наряда показан сохранённый анализ: режим, вывод, краткий итог, замечания и необходимость решения мастера
- `rules-only` явно означает проверку правил; смысловая проверка моделью не заявляется. Режим модели показывается только при совпадающих серверных метках `ai_mode` / `ai_result.mode` и читаемом основном результате. Это сведения о сохранённом ответе сервера, не проверка живой модели
- Фото и материалы показаны отдельными проверками при наличии данных. Оценка проверяемости файла не выдаётся за качество ремонта; учебное сравнение не считается утверждённой нормой расхода
- Оценка содержания отчёта моделью `report_score`, её обоснование `score_reason` и уверенность `confidence` отделены от окончательной оценки мастера
- После закрытия наряда исполнитель, мастер и руководитель видят итоговую оценку `rating` и обоснование `rating_reason`, даже если анализа нет
- Анализ, сохранённый до доработки/повторной сдачи, явно обозначен как предыдущий. Он не выдаётся за проверку исправленного отчёта
- Nullable, повреждённый JSON, неизвестные типы/поля/режимы не приводятся к строкам. Данные ограничены по размеру; технические поля и сырой JSON не выводятся, распознаваемые строки с учётными данными скрываются
- 535 записей RU/KK/EN. Добавлены точные переводы четырёх ошибок сервера: дубль фото, лимит активных фото, ожидание очистки, отсутствие активного исполнителя в бригаде
- Спокойная прежняя светлая/тёмная палитра. Новые блоки имеют переносы без фиксированной высоты; приложены тесты для ширины 320 px и масштаба текста 200% во всех трёх языках

Интерфейс и известные стандартные серверные сообщения переводятся. Произвольный текст модели/наряда и комментарий мастера сохраняются на исходном языке. Внешний сервис перевода не вызывается.

## Установка

1. Сохраните резервную копию текущего `mobile_flutter`
2. Скопируйте `lib`, `test`, `tool` из этого пакета с заменой совпадающих файлов. Не удаляйте Android/iOS-каталоги и остальные файлы своего проекта
3. `pubspec.yaml` совпадает с согласованной v2, зависимости в v3 не менялись. Если ваш текущий файл уже дополнен, не заменяйте его вслепую; сверьте зависимости с `pubspec.dependencies.fragment.yaml`
4. Выполните в текущем Flutter-проекте:

```sh
flutter pub get
dart format lib test tool
flutter analyze
flutter test
dart tool/ai_review_regression.dart
dart run tool/api_transport_regression.dart
dart run tool/api_photo_regression.dart
flutter run
```

Для Flutter используйте текущий SDK проекта; исходная v2 использует Flutter 3.35+, а ранее переданный lockfile требовал Flutter 3.38+ / Dart 3.10+. Не понижайте SDK. Установку SDK и создание APK этот пакет не выполняет.

## Границы изменений

API, Content-Length при входе, cookies/CSRF, роли, разрешения, доступ к защищённым фото, создание/приёмка наряда и Telegram не менялись. На действующий сервер запросы не отправлялись. Модель, ключи, внешний AI-провайдер или Telegram не включались.

Новый экран только отображает уже возвращённые сервером поля. Кнопки анализа/приёмки остаются в прежнем ролевом интерфейсе. Сервер и его отдельное исправление переназначения бригады в этот архив не включены.
